# 슈퍼로봇대전 Y · 시나리오 에디터와 IF 로더

직접 만든 대사, 전투맵 이벤트, 실제 전투를 하나의 미션으로 연결하고 게임에서 확인하기 위한 Windows용 제작 도구입니다. 다른 사람이 만든 작품 ZIP을 가져와 수정하거나, 자신의 작품을 공유할 수 있습니다.

**현재 배포는 2026.10.01 Preview R3 시험 버전입니다.** 정식 출시본이 아니며, 설치된 슈퍼로봇대전 Y 1.4.0 한국어 게임이 필요합니다. 이 저장소는 프로그램 다운로드와 사용 안내를 제공합니다.

## 다운로드

[릴리스 다운로드 페이지](https://github.com/subungeee/SRWY-IF-Tools/releases)에서 **SRWY_IF_Tools_2026-10-01_Preview_R3.zip**을 받으세요.

GitHub가 자동으로 붙이는 **Source code (zip)** 대신 위 프로그램 ZIP을 선택해야 합니다. 자동 생성된 Source code 압축본에는 에디터 실행 파일이 없습니다.

## 필요한 환경

- Windows 10 또는 11, 64비트
- 설치된 슈퍼로봇대전 Y **1.4.0 한국어판**
- Microsoft Edge WebView2 Runtime
- 게임 설치 용량만큼의 별도 IF 게임 사본 공간과 편집 자료·썸네일을 저장할 추가 공간

Python과 .NET 개발 도구를 따로 설치할 필요는 없습니다. WebView2가 없는 PC에서는 [Microsoft 공식 WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)을 설치하세요. 다른 게임 버전이나 언어판의 작동은 확인하지 않았습니다.

## ZIP에 들어 있는 파일

| 파일 | 역할 |
| --- | --- |
| 01_SRWY_Setup.exe | 게임 폴더와 자료 저장 위치를 선택하는 설치·연결 도구 |
| 02_SRWY_Editor.exe | 작품과 미션을 만들고 수정하는 시나리오 에디터 |
| 03_SRWY_Loader.exe | 전달된 IF 시나리오를 게임에서 실행하는 로더 |
| _internal 폴더 | 실행에 필요한 라이브러리와 보조 도구 |
| 설치방법.txt | 기본 설치 안내 |
| SHA256SUMS.txt | 배포 파일별 확인용 해시 |

**게임 실행 파일, 원본 게임 자산, 추출된 게임 그림·음악·지도, 개인 작품, 개인 세이브는 배포 ZIP에 포함하지 않습니다.** 필요한 편집 자료는 사용자가 설치한 게임에서 로컬로 준비합니다.

## 처음 설치하기

1. 프로그램 ZIP 전체를 원하는 폴더에 풉니다. EXE만 꺼내지 말고 _internal 폴더도 함께 두세요.
2. **01_SRWY_Setup.exe**를 실행합니다.
3. 본인 PC에 설치된 Y 게임 폴더와 자료를 저장할 폴더를 선택합니다.
4. 설치 도구가 해당 게임에서 편집 자료와 별도 IF 게임 실행 사본을 준비합니다. 첫 준비에는 시간이 걸리며 저장 공간도 필요합니다.
5. 완료 후 **02_SRWY_Editor.exe**를 엽니다.
6. 게임 자료 준비가 진행 중이어도 에디터에서 작품을 편집할 수 있습니다. 준비된 썸네일은 다음 실행에서 재사용합니다.

원본 게임과 기존 세이브를 보존하고 별도 IF 실행본·진행 프로필을 사용하는 구성입니다. 설치 후 프로그램 폴더를 옮겼다면 설치 도구를 다시 실행해 연결과 바로가기를 갱신하세요.

## 작품 제작과 게임 전달

에디터의 작품 목록에서 새 작품을 만들거나 기존 작품을 엽니다. 작품에는 여러 임무를 넣고 작품 흐름 차트로 연결할 수 있습니다.

미션 안에서는 대화 장면, 전투맵 이벤트, 실제 전투와 조건 이벤트를 편집합니다. 대사·배치·동작을 수정한 뒤 **저장 → 게임 테스트**로 현재 저장본의 게임용 출력을 만들고 연결된 IF 실행본에 전달합니다.

게임이 실행 중이면 먼저 종료한 뒤 전달하세요. 전달한 작품은 **03_SRWY_Loader.exe** 또는 생성된 IF 실행 바로가기로 확인할 수 있습니다. 에디터의 그림·맵·연출 미리보기만으로 실제 게임 플레이를 모두 검증한 것은 아닙니다.

설치된 추가 자료 중 일부는 편집 미리보기용으로만 연결되어 있습니다. 목록에 그림이 보이더라도 모든 추가 기체·인물이 실제 게임 출력까지 지원된다는 의미는 아닙니다. 게임 출력 제한은 에디터의 해당 항목에서 확인하세요.

## 시나리오를 다른 사람에게 공유하기

1. 공유할 작품을 에디터에서 엽니다.
2. 상단 **더보기 → 공유 ZIP 내보내기**를 누릅니다.
3. 생성된 작품 ZIP을 다른 사용자에게 전달합니다.

공유 ZIP에는 편집 가능한 작품 문서와 자산 참조만 들어갑니다. 게임 원본, 썸네일 캐시, 로더, 세이브, 보내는 PC의 설치 연결 파일은 함께 넣지 않습니다. 따라서 프로그램 설치 ZIP과 작품 공유 ZIP은 서로 다른 파일입니다.

대사·장면·배치·이벤트·작품 연결이 공유 대상입니다. 실제 파일 크기는 작품 내용에 따라 달라집니다. 대사 8장면과 이벤트 5개가 있는 확인용 미션은 약 **4.3KB**였습니다. 공유 작품 ZIP의 현재 입력 한도는 **4MB**입니다.

## 받은 작품 설치·수정하기

- 받은 작품 ZIP을 **에디터 창에 끌어놓거나**, 작품 목록의 **작품 ZIP 가져오기**로 선택합니다.
- 작품이 자동으로 등록되고 열립니다. 편집한 대사와 이벤트를 다시 수정할 수 있습니다.
- 같은 ZIP을 다시 가져와도 새 작품 ID로 등록해 기존 편집 사본을 덮어쓰지 않습니다.
- 편집 중인 작품에 미저장 변경이 있으면 먼저 자동 저장을 시도합니다. 저장에 실패하면 기존 편집 내용을 유지합니다.
- 받는 PC에 없는 추가 자료 참조는 안내합니다. 필요한 자료를 다시 선택하거나 교체하세요.
- 플레이하려면 받는 PC에서 **저장 → 게임 테스트**로 자기 게임에 전달해야 합니다. 작품 ZIP만 풀었다고 바로 게임용 파일이 설치되는 구조는 아닙니다.

일반 ZIP이나 프로그램 설치 ZIP은 작품 가져오기 대상으로 사용할 수 없습니다. 에디터의 공유하기로 만든 작품 ZIP을 선택하세요.

## 게임에 등록된 시나리오 따로 관리하기

작품 목록 또는 상단 **더보기 → 게임 시나리오 관리**를 엽니다.

- **편집 열기:** 이 PC에 편집 원본이 있는 등록 작품을 에디터에서 엽니다.
- **검색·상태 필터:** 제목으로 찾거나 게임 목록에 있는 작품과 제외한 작품을 구분합니다.
- **위·아래 이동:** 게임 목록의 시나리오 순서를 변경합니다.
- **게임 목록에서 제외:** 게임의 일반 시나리오 목록에서 빼되 편집 작품, 게임용 파일과 진행 기록은 보존합니다.
- **다시 등록:** 제외한 작품을 게임 목록으로 되돌립니다.

목록 제외는 영구 삭제가 아닙니다. 파일을 다시 추출하거나 출력하지 않고 기존 게임 목록의 표시 상태를 변경합니다. 목록 변경은 게임을 종료한 상태에서 하세요. 에디터 작품 목록에서 작품을 제거하는 기능과 게임 목록에서 제외하는 기능은 별개입니다.

## 현재 확인 범위와 남은 제한

기존 시험 배포에서 개발 폴더 밖 EXE 설치, 편집 저장, 게임용 출력과 로더 전달을 확인했습니다. R3에서는 새 EXE의 공유 ZIP 가져오기·내보내기, 가져온 작품 재저장, 중복 가져오기 시 ID 분리, 게임 목록 제외·복원과 Host 파일 보존을 확인했습니다.

새 기능 관련 직접 테스트 9개가 통과했습니다. 원본 게임 자산을 작품 ZIP에 넣지 않는 것도 확인했습니다. 다만 **다른 실물 PC에서의 실제 게임 플레이와 모든 이벤트 조합은 아직 확인하지 않았습니다.**

로더는 기존 시험 버전을 함께 제공합니다. 게임 창 전환 뒤 응답이 없어지는 문제가 별도로 수정 중입니다. 이 배포에 그 문제의 해결을 포함했다고 주장하지 않습니다.

첫 자료 추출·썸네일 준비 속도, 일부 추가 자료의 게임 출력 지원과 미리보기 정확도도 계속 보완할 항목입니다. 오류 제보에는 프로그램 버전, 어떤 화면·조작에서 발생했는지, 오류 문구를 함께 적어 주세요. 개인 설치 경로·세이브·게임 원본을 공개로 올릴 필요는 없습니다.
