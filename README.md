# 슈퍼로봇대전 Y · 통합 에디터와 IF 로더

시나리오 에디터와 IF 로더를 한 프로그램에서 사용하는 Windows용 도구입니다. 홈에서 게임 실행·받은 작품 등록·미션 편집·로더 설치와 되돌리기를 선택합니다.

**현재 배포: 2026-10-30 Steam 1.4.1 로딩 개선 시험판.**

## 설치와 실행

Windows 10/11 64비트, 설치된 슈퍼로봇대전 Y **Steam 1.4.1 한국어판**과 Microsoft Edge WebView2 Runtime을 대상으로 합니다.

1. ZIP 전체를 새 프로그램 폴더에 풉니다. 압축 안의 `Editor/SRWY_IF_Editor.exe`와 `_internal` 폴더를 함께 두세요.
2. `SRWY_IF_Editor.exe`를 열고 본인 PC의 게임 설치 폴더를 선택합니다. 기본 Steam 라이브러리는 `steamapps/common/SRWY`입니다.
3. 설치가 필요하면 게임을 종료한 뒤 홈의 **로더 설치·관리**에서 설치 계획을 확인하고 적용합니다. 제거·복원도 같은 도구를 사용합니다.
4. 받은 플레이용 작품은 홈에서 등록하고, 미션을 만들거나 수정할 때는 **에디터 열기**를 선택합니다. 게임 실행·작품 등록은 편집 자료 준비를 기다리지 않습니다.
5. 이전 개인 작품·임시저장·세이브·준비 자료를 보관하고 이어 사용하세요. 이전 프로그램 파일과 새 `_internal`을 섞지 마세요.

설치된 게임 하나에 연결하며 게임 전체 사본이나 별도 재설치를 만들지 않습니다. 확장팩 전체나 클리어 세이브를 앱 시작 조건으로 두지 않지만, 작품에 실제로 쓰인 게임 자료는 필요합니다.

ZIP에는 실행 프로그램과 보조 라이브러리가 들어 있습니다. 게임 원본·추출 그림/음악/지도·개인 작품·세이브는 포함하지 않습니다.

## 확인 범위

현재 공개 ZIP은 지정된 로딩 개선 배포 폴더의 1,790개 파일과 크기·SHA-256이 모두 일치합니다. 이번 업로드 과정에서 이 ZIP을 별도로 실행하거나 로딩 시간을 측정하지는 않았습니다. 다른 PC·확장팩 미설치 환경·모든 기체와 이벤트 조합은 별도 확인이 필요합니다.
