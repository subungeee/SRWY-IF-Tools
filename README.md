# 슈퍼로봇대전 Y · 통합 에디터와 IF 로더

Claude의 최신 편집 화면과 IF 로더를 한 프로그램에서 사용하는 Windows용 도구입니다. 홈에서 게임 실행·받은 작품 등록·미션 편집·로더 설치와 되돌리기를 선택합니다.

**현재 배포: 2026-10-29 통합 r7 시험판.** 홈·편집·작품 등록은 확인했으며, 시험 작품의 전투맵 진입에서 검은 맵 오류가 확인돼 수정 중입니다. 정상 전투 진행과 저장 후 재개는 아직 확인을 마치지 않았습니다.

## 달라진 사용 흐름

- 에디터와 로더를 `SRWY_IF_Editor.exe` 하나로 엽니다.
- 게임 실행과 플레이용 작품 등록은 편집 자료 준비를 기다리지 않습니다.
- 편집을 열면 기존 준비 자료와 개인 작품을 이어 사용합니다.
- 미저장 상태의 홈 이동 확인, 취소, 홈 복귀, 편집 재진입과 임시저장 복구를 연결했습니다.
- 확장팩 전체 보유나 클리어 세이브를 앱 시작 조건으로 두지 않습니다. 선택한 작품에 실제로 쓰인 게임 자료는 필요합니다.
- 설치된 게임 하나에 연결합니다. 게임 전체 사본이나 별도 게임 재설치를 만들지 않습니다.

## 설치와 실행

Windows 10/11 64비트, 설치된 슈퍼로봇대전 Y 1.4.0 한국어판과 Microsoft Edge WebView2 Runtime을 기준으로 합니다. 다른 PC·게임 판본과 실제 확장팩 미설치 환경은 아직 별도 확인 전입니다.

1. ZIP 전체를 새 프로그램 폴더에 풉니다. `SRWY_IF_Editor.exe`와 `_internal` 폴더를 함께 두세요. 이전 R3 프로그램 파일과 섞어 덮어쓰지 않습니다.
2. `SRWY_IF_Editor.exe`를 열고 본인 PC의 게임 폴더를 선택합니다.
3. 설치가 필요하면 게임을 종료한 뒤 홈의 **로더 설치·관리**에서 설치 계획을 확인하고 적용합니다. 되돌릴 때도 같은 도구를 사용합니다.
4. 받은 플레이용 작품은 홈에서 등록합니다. 미션을 만들거나 수정할 때는 **에디터 열기**를 선택합니다. 최초 편집 준비는 설치된 게임의 자료를 읽어 진행합니다.
5. 기존 개인 작품·세이브·준비 자료는 보관하고 새 프로그램에서 이어 사용합니다.

ZIP에는 실행 프로그램과 보조 라이브러리가 들어 있습니다. 게임 원본·추출 자산·개인 작품·세이브는 포함하지 않습니다.

## 확인한 범위와 현재 문제

중앙 시험에서 홈과 Claude 편집 화면의 왕복, 미저장 이동 취소, 임시저장 복구·저장, 플레이용 ZIP/폴더 등록과 중복 등록 보존을 확인했습니다. 로더 회귀 11건·설치 적용/복원·기존 모듈 보존과 동봉 native 판독도 확인했습니다.

실제 게임에서는 타이틀·메뉴와 짧은 시험 프로필의 첫 저장까지 확인했습니다. 이후 시험 작품의 전투맵 초기화에서 **메뉴 입력은 되지만 맵이 검게 남는 오류**가 발생했습니다. 정상 맵 표시·기체 조작·전투·저장 후 종료/재개·완료 복귀는 후속 수정과 시험이 필요합니다. 이 통합 r7은 해당 문제가 해결됐다고 표시한 배포본이 아닙니다.

기존 긴 시험 경로에서는 첫 저장 실패도 관찰됐습니다. 짧은 프로필에서 첫 저장은 통과했으나 경로 길이를 확정 원인으로 단정하지 않습니다. 오류 제보에는 프로그램 버전·화면·수행한 조작·오류 문구를 적어 주세요.
